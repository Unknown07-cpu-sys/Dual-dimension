# Dual Dimensions

A puzzle game where you control two characters in parallel worlds, moving both at once to reach the exits.

🎮 **Play now:** https://Unknown07-cpu-sys.github.io/Dual-dimension/

![Screenshot](screenshot.png)

## 🤖 Made entirely by AI

This game was designed and coded entirely by AI, using [Claude](https://claude.ai) by Anthropic. The concept, puzzle design, code and gameplay all came out of prompts and iteration.

## Features

- Dual-world puzzles: both characters move together, and both must reach the exits
- Switch and gate mechanics: stepping on a switch opens the matching gate in the other world
- Multiple levels with saved progress and best move counts
- Undo and reset
- Mobile-friendly swipe controls

## Controls

| Action | Keyboard | Touch |
|---|---|---|
| Move | Arrow keys / WASD | Swipe |
| Undo | Z | Undo button |
| Reset level | R | Reset button |

## Built with

- [Phaser 3](https://phaser.io/)
- HTML, CSS and JavaScript
